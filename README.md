# UltraWorld project page

Project website: https://ultraworld-project.github.io/

Static website containing the displayed figures, table screenshots, 17 comparison videos, four opening previews, and the AsMap animation. The Paper button links to the published PDF at `assets/UltraWorld.pdf`. The arXiv link is coming soon; research code will be available after review.

## Development

Edit `index.html`, `style.css`, `app.js`, or the displayed media in `assets/`. No build is required. Preview with `python3 -m http.server 8765 --bind 127.0.0.1`.

GitHub Pages publishes the repository root on the `main` branch. Commit and push changes to update the website. Only the explicitly selected paper PDF is included; keep other manuscripts and unrelated research files out of this repository.

## Attribution

The layout uses styles from Astra and Bulma. Third-party stylesheet and font license notices are retained in `assets/vendor/`. Tables are screenshots from the paper, with link annotations hidden.
